# RSS It Later

**This project is still under development.**

When it's done, you'll be able to publish articles to your own RSS feed that you then can add in the RSS reader of your choice.
The idea is to build a simple "Save it later"-service not tied to any specific platform.
Think [Instapaper](https://instapaper.com), but without the app, neatly integrated into your specific workflow.
